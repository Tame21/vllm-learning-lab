# 数据与隐私

## 项目发布的内容

仓库只包含工具代码、教学数据、测试和文档。参考源码缓存、构建生成物、依赖、浏览器测试记录、日志、本机环境变量和编辑器配置均在 `.gitignore` 中排除。源码阅读器显示仓库相对路径，例如 `vllm/v1/engine/core.py`，不需要开发者机器上的目录名。

`npm run check:release` 检查实际 Git 暂存内容，而不是仅检查工作区。它会拦截缓存和生成物、个人目录路径、常见 GitHub 令牌、私钥和带凭据的 URL。检查结果只显示文件名、行号和风险类型，不回显秘密。它是提交前的辅助检查，不能识别所有形式的敏感数据。

## 浏览器保存什么

- 仅在当前站点的 `localStorage` 中保存已读进度、理解题、收藏、专题参数与断点。
- 分享的实验链接可以包含教学参数、步骤和页签，不包含成绩。分享前仍应检查 URL。
- 启动命令只在当前页面内存中解析，不执行，不写入 localStorage 或实验链接，不发送给外部服务。
- 参数表会遮盖已识别的密钥字段；输入框仍保留原始命令，截图前应移除令牌、私人模型路径和内部地址。掩码不是通用脱敏器。

清理本工具站点的浏览器存储即可删除本机学习记录。不同端口属于不同站点，记录不会自动合并。

## 网络和本机访问

初次准备源码时，Git 访问官方 GitHub 仓库，使用本机已有的 Git 网络设置。缓存准备好后，学习页面不需要外部网络，没有分析埋点或外部字体依赖。

本机服务只提供前端与所选参考源码中的允许文本类型，拒绝隐藏目录、目录越界和指向源码目录外的符号链接。不接收上传，不提供任意文件读取或 shell 执行接口。可选的浏览器代理接口只操作页面中的教学专题和参数。
