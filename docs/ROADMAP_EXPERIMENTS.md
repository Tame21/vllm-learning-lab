# 路线新增观察窗：逐项实验指南

本轮新增 39 个观察窗，原有专题 ID、进度、理解题与源码入口保持连续。先选择一个场景，再单步回放；修改参数从头重算，短 token 历史按 Enter 应用。所有模型数值、时隙、网络与设备行为均为显式教学输入。

来源基准仍为固定 vLLM 提交 `84030bbe3d74d99bad477a3d2e37a973ccd8865c`。原有观察窗操作见 [机制指南](MECHANISM_EXPERIMENTS.md)，完成清单见 [路线盘点](VISUALIZATION_ROADMAP.md)。

## 核心示意图升级

### 1. Prefill 与 Decode（prefill）

跟随 Q/K/V 行和缓存增长，确认最后一枚输出的 KV 尚未写入；EOS 后不再前向。

可调输入：Prompt 位置数、教学输出上限、第几枚输出为 EOS（0 关闭）。

场景：“多轮 Decode”、“第一枚输出即 EOS”、“较长 Prompt”。

教学边界：Q/K/V 与 token ID 是教学值；已采样 token 的 KV 在下一次前向才写入。

### 2. 采样、温度与 Top-p（sampling）

按 logits → 温度 → Softmax → Top-p → 重归一化 → 指数竞赛回放；T=0 跳过随机分支。

可调输入：Temperature、Top-p。

场景：“随机采样”、“贪心 T=0”、“较小 Top-p”。

教学边界：五词固定 logits；指数竞赛的随机流可复现，但不是 PyTorch / CUDA 随机流。

### 3. 权重量化与精度（quantization）

观察逐元素缩放、舍入、有符号整数和 INT4 字节打包，再从字节恢复数值。

可调输入：教学量化位宽。

场景：“INT8 编码”、“INT4 打包”。

教学边界：对称量化、半格远离零；INT4 打包约定首元素在低四位，不代表 AWQ / GPTQ 布局。

### 4. 上下文并行 PCP / DCP（cp）

DCP 用局部输出和 LSE 合并；PCP 先分 Q/K/V，再 Gather KV，结果与全量因果 Attention 对照。

可调输入：教学 CP rank 数、PCP：局部 Q / Gather KV、PCP 观察 query 位置。

场景：“DCP / LSE 合并”、“PCP / Gather KV”、“PCP 早期 query”。

教学边界：固定八位置、单头二维 Attention；DCP 观察末位置，PCP 可选 query。连续切片是教学布局。

### 5. 专家负载均衡 EPLB（eplb）

先构建影子布局、迁移所有目标权重，再越过屏障切换映射；旧布局在迁移期间继续有效。

可调输入：专家 0 负载倍率、冗余物理副本数、每槽迁移确认时隙。

场景：“热点专家复制”、“均衡负载”、“无冗余副本”。

教学边界：两设备、四逻辑专家；复用算法章的单层教学分配，权重就绪后才切换映射。

### 6. LoRA 与多适配器推理（lora）

同批 A/B/base 输入逐行绑定适配器，计算 Wx 和 B(Ax)；反转行顺序后请求结果保持一致。

可调输入：教学低秩 r、增量比例（已含 alpha/r）、反转批次行顺序、请求 B 使用基础模型。

场景：“混合适配器批次”、“反转行顺序”、“零增量对照”。

教学边界：三个请求、四行输入共用 W；A/B 使用不同适配器，C 的映射为 base。

### 7. 图像、视频与音频输入（multimodal）

分别观察图像行、视频帧与音频特征的占位对应；重复键复用 encoder，数量不符时阻止前向。

可调输入：教学媒体类型、媒体出现次数、重复使用同一媒体内容、占位符少一个位置。

场景：“重复图像 / 缓存命中”、“视频帧对齐”、“音频特征对齐”、“占位数量不匹配”。

教学边界：向量与占位数量为教学配置；展示逐行对应，模型位置编码与真实 encoder 另有约束。

## 投机方法可编辑输入

### 8. N-gram：从历史复制草稿（ngram）

编辑短历史后按 Enter，观察最长后缀窗口、最早匹配位置、复制范围与共同贪心验证。

可调输入：候选上限 K、教学目标首个不匹配位置（0 全收）、请求 A 的 token 历史、请求 B 的 token 历史、最长后缀窗口、Anchor token、教学隐藏特征首维、辅助特征层数、匹配模型具备索引共享接口、草稿模型具备并行训练配置、教学上下文 KV 位置数、教学 Markov 偏置幅度、示例路径最低条件频率、请求 B 不允许提出草稿、DSpark anchor 也预测第一枚候选。

场景：“重复后缀”、“没有历史匹配”、“全部候选接受”。

教学边界：空格分隔 1–24 个短 token；计算最长后缀的最早历史匹配，不调用模型。

### 9. N-gram GPU：在设备上查历史（ngram-gpu）

比较 A/B 的有效长度与 pad=-1；屏蔽 B 后它不产生候选。本窗口只计算 GPU 输入输出契约。

可调输入：候选上限 K、教学目标首个不匹配位置（0 全收）、请求 A 的 token 历史、请求 B 的 token 历史、最长后缀窗口、Anchor token、教学隐藏特征首维、辅助特征层数、匹配模型具备索引共享接口、草稿模型具备并行训练配置、教学上下文 KV 位置数、教学 Markov 偏置幅度、示例路径最低条件频率、请求 B 不允许提出草稿、DSpark anchor 也预测第一枚候选。

场景：“不同有效长度”、“屏蔽请求 B”、“两行无匹配”。

教学边界：两行历史有效长度独立；−1 是候选填充，不能作为有效 token 提交。

### 10. Suffix：按频次选择历史续写（suffix）

调整频次门限，观察经验后缀树的条件概率与候选路径停止；未知上下文保持无候选。

可调输入：候选上限 K、教学目标首个不匹配位置（0 全收）、请求 A 的 token 历史、请求 B 的 token 历史、最长后缀窗口、Anchor token、教学隐藏特征首维、辅助特征层数、匹配模型具备索引共享接口、草稿模型具备并行训练配置、教学上下文 KV 位置数、教学 Markov 偏置幅度、示例路径最低条件频率、请求 B 不允许提出草稿、DSpark anchor 也预测第一枚候选。

场景：“频次树续写”、“高门限停止”、“未知后缀”。

教学边界：固定训练片段与当前历史构成频次树；不复现外部 Arctic 后缀库。

### 11. Draft Model：独立小模型逐词起草（draft-model）

每个候选成为下一次草稿输入；区分已输入位置的 KV 与尚未输入的最后候选。

可调输入：候选上限 K、教学目标首个不匹配位置（0 全收）、请求 A 的 token 历史、请求 B 的 token 历史、最长后缀窗口、Anchor token、教学隐藏特征首维、辅助特征层数、匹配模型具备索引共享接口、草稿模型具备并行训练配置、教学上下文 KV 位置数、教学 Markov 偏置幅度、示例路径最低条件频率、请求 B 不允许提出草稿、DSpark anchor 也预测第一枚候选。

场景：“串行草稿”、“更长候选链”、“全收与 bonus”。

教学边界：候选使用教学数据；目标验证采用明确的贪心对照，首次不匹配后不提交剩余草稿。

### 12. EAGLE：借助目标隐藏状态起草（eagle）

逐步对齐 token、position 和目标特征，再使用教学递推状态生成候选。

场景：“隐藏状态对齐”、“改变隐藏特征”、“首项拒绝”。

教学边界：token 与目标隐藏状态按位置对齐；示例递推不执行 EAGLE 权重。

### 13. EAGLE3：融合目标的多层特征（eagle3）

可调输入：候选上限 K、教学目标首个不匹配位置（0 全收）、请求 A 的 token 历史、请求 B 的 token 历史、最长后缀窗口、Anchor token、教学隐藏特征首维、辅助特征层数、匹配模型具备索引共享接口、草稿模型具备并行训练配置、教学上下文 KV 位置数、教学 Markov 偏置幅度、示例路径最低条件频率、请求 B 不允许提出草稿、DSpark anchor 也预测第一枚候选。

### 14. MTP：使用模型的多 Token 预测模块（mtp）

对照条件性的 IndexCache 共享与重新计算，不将模型专属模块画成通用 MTP 架构。

可调输入：候选上限 K、教学目标首个不匹配位置（0 全收）、请求 A 的 token 历史、请求 B 的 token 历史、最长后缀窗口、Anchor token、教学隐藏特征首维、辅助特征层数、匹配模型具备索引共享接口、草稿模型具备并行训练配置、教学上下文 KV 位置数、教学 Markov 偏置幅度、示例路径最低条件频率、请求 B 不允许提出草稿、DSpark anchor 也预测第一枚候选。

### 15. MLP Speculator：轻量级联预测（mlp-spec）

仅演示级联输入依赖，终态明确保持未接入；不追加接受数、bonus 或可执行配置。

### 16. Medusa：同一隐藏状态上的多个预测头（medusa）

同一隐藏状态扇出到独立预测头，各头并列组成候选，额外骨干前向为零。

可调输入：候选上限 K、教学目标首个不匹配位置（0 全收）、请求 A 的 token 历史、请求 B 的 token 历史、最长后缀窗口、Anchor token、教学隐藏特征首维、辅助特征层数、匹配模型具备索引共享接口、草稿模型具备并行训练配置、教学上下文 KV 位置数、教学 Markov 偏置幅度、示例路径最低条件频率、请求 B 不允许提出草稿、DSpark anchor 也预测第一枚候选。

### 17. PARD：一次前向提议多个位置（parallel-draft）

观察 anchor 与 K−1 个 mask 一次进入骨干；关闭训练准备条件后保持阻塞。

场景：“并行查询块”、“模型配置不匹配”、“五位置对照”。

### 18. DFlash：上下文 KV 与并行 Mask 块（dflash）

### 19. DSpark：并行骨干与顺序 Markov 头（dspark）

## 输入、服务与故障协议

### 20. 语音转写与流式输入（speech）

音频块抵达、编码、分组提交和文本上下文续接分开，重复提交计数保持一次。

可调输入：教学音频块数、每组提交的音频块、所选模型支持流式续接。

场景：“分组音频续接”、“逐块提交”、“模型不支持续接”。

教学边界：音频向量与转写片段为教学数据；缓冲和续接能力由真实模型接口决定。

### 21. 工具调用与推理内容（tools）

缩小字符块大小，观察不完整标签保留在 parser 缓冲区；合法 JSON 才交付工具对象。

可调输入：教学文本块字符数、工具 JSON 缺少右括号、启用匹配的教学 parser。

场景：“跨块工具参数”、“小块标记边界”、“损坏的工具 JSON”、“关闭 parser”。

教学边界：scratch_pad / tool_call 教学标记；展示跨块缓冲与完整 JSON 检查，不执行工具。

### 22. 交错思考与思考预算（thinking）

零预算和多 token 结束标记按顺序强制；交错段分别重置计数，正文不扣思考预算。

可调输入：每段教学思考 token 预算、结束标记 token 数、正文后再次进入思考、配置已知的思考结束 token。

场景：“分段思考预算”、“零预算立即退出”、“缺少结束标记配置”。

教学边界：非投机、单请求状态机；预算为 0 时直接强制结束标记，结束序列可以有多个 token。

### 23. Encoder 分离与 EC 缓存（encoder-disagg）

媒体特征完成传输确认后才可被 LM 使用；同内容复用 EC，失败不前向。

可调输入：媒体任务数、任务共享媒体内容、共享 EC 已有有效特征、特征传输时隙、特征传输失败。

场景：“编码后复用 EC”、“已有 EC 缓存命中”、“传输失败阻止 LM”。

教学边界：EC 是 encoder 特征；到达消费侧并确认后才可用于媒体占位，不与 K/V 混用。

### 24. 服务协议与流式响应（serving）

逐段查看 SSE JSON，role/content/finish/usage/[DONE] 保持 FIFO；慢客户端增加队列，断连停止生成。

可调输入：教学输出片段数、客户端消费间隔、末尾包含 usage 块、产生第几个片段时断连（0 关闭）、请求校验失败。

场景：“SSE 与 usage”、“慢客户端积压”、“第二片段断连”、“请求无效”。

教学边界：展示 OpenAI Chat Completions SSE 的简化响应；人工时隙只用于观察输出队列。

### 25. 故障检测与资源清理（fault）

区分逻辑块释放与在途物理任务确认；worker 故障终止所有请求，单请求取消保留另一请求。

可调输入：仅取消 A（关闭则 worker 故障）、在途工作确认时隙、示例恢复策略成功。

场景：“Worker 故障传播”、“只取消请求 A”、“恢复失败保留错误”。

教学边界：调度块释放和在途物理工作确认分开；恢复健康不会自动重放已中止的请求。

## 配置与平台条件分支

### 26. 从配置到引擎（configuration）

命令分析器先分组配置，再检查头数/TP 与 Runner/投机方法组合；失败不生成请求路径。

可调输入：教学 TP 大小、教学模型 Attention 头数、选择 MRV2、请求 N-gram 投机。

场景：“配置分组与校验”、“头数不能整除 TP”、“MRV2 与 N-gram 冲突”。

教学边界：复用启动命令分析器；模型头数为显式教学条件，未加载真实配置。

### 27. Attention 后端选择（attention-backends）

逐项过滤两个 Dense Attention 候选，查看所有淘汰原因；没有候选时不生成可执行元数据。

可调输入：Attention head size、计算 dtype、教学 CUDA capability 主版本、KV kernel block size、FlashAttention 4 可用、模型请求 MLA。

场景：“Dense 后端条件”、“小 head 仅 Flash 通过”、“无候选 / block 不合法”、“MLA 排除 Dense 后端”。

教学边界：检查 FLASH_ATTN / TRITON_ATTN 已核对的条件子集；不是完整平台后端自动选择器。

### 28. 自适应验证与接受率（adaptive-spec）

条件置信度连乘形成存活概率；按教学成本曲线选择跨请求预算并保留每请求前缀。

可调输入：A 各位置条件置信度、B 各位置条件置信度、教学计算饱和成本、满足 DSpark 置信度与后端要求。

场景：“跨请求存活分配”、“高计算成本”、“低置信度 A”、“不满足支持条件”。

教学边界：两请求各三个位置；存活概率为条件置信度连乘，成本曲线是教学输入。

### 29. 硬件平台与 Kernel 分发（platform）

选择平台查看 CustomOp 基类方法委托；缺少 native 实现时保持错误，不标为成功执行。

可调输入：CustomOp 分发平台、启用 CustomOp、教学算子实现 forward_native、教学标量输入 x。

场景：“CUDA 分发”、“CPU 默认 native”、“关闭 CustomOp”、“缺少 native 实现”。

教学边界：只核对 CustomOp 基类分发；教学算子实现 CUDA 与可选 native，不据此推断模型支持。

### 30. 特性组合与支持边界（compatibility）

切换组合逐项列出触发条件、冲突理由与源码；只承诺已检查规则的结果。

可调输入：投机方法、请求自适应验证、启用 LoRA、PP 大于 1、Enforce Eager、选择 MRV2。

场景：“已检查条件通过”、“自适应与 LoRA 冲突”、“自适应与 Eager 冲突”、“N-gram 与 MRV2 冲突”。

教学边界：检查固定版本已确认的五类组合限制；通过这些条件不等于所有模型和平台都支持。

## 模型与接入边界

### 31. MLA、稀疏注意力与 IndexCache（mla）

将 latent/RoPE 表示、Top-k 稀疏索引和 F/S 跨层复用拆开；S 层不重新计算索引。

可调输入：教学低秩 latent 维度、每隔几层计算 F 索引、稀疏索引 Top-k。

场景：“低秩与跨层复用”、“每层计算索引”、“一维 latent 对照”。

教学边界：低秩表示、稀疏索引与 IndexCache 三件事分别观察；示例矩阵不是 DeepSeek 权重。

### 32. 草稿训练数据与 Speculators（speculators）

按同一 token 位置 stack 辅助层，展示 next-token 样本与导出结构；层错位时禁止导出。

可调输入：教学 token 位置数、提取的辅助层数、最后一层少一行、已有匹配的外部训练 checkpoint。

场景：“对齐隐藏状态数据”、“辅助层形状错误”、“外部 checkpoint 已就绪”。

教学边界：提取模式缓存目标隐藏状态，返回目标 sampled token；外部训练不会在页面执行。

### 33. 弹性 EP 与扩缩容（elastic）

所有逻辑专家的目标权重与通信组屏障确认后才切拓扑；失败保留原 epoch/world。

可调输入：目标教学 EP world size、迁移确认时隙、新通信组屏障成功。

场景：“两 rank 扩到四 rank”、“缩到一个 rank”、“切换屏障失败”。

教学边界：初始两 rank、四逻辑专家；目标布局和迁移为教学状态，不启动分布式进程。

### 34. 长上下文、RoPE 与混合模型（long-context）

成对旋转数值与向量范数可检查；窗口改变可访问历史，超 max_len 时阻止生成缓存。

可调输入：观察 position、教学 max_model_len、线性角度缩放因子、窗口可见长度（0 全历史）。

场景：“位置与窗口历史”、“完整历史对照”、“超过长度上限”。

教学边界：单头四维 RoPE 的线性位置缩放示例；不代表 YaRN、模型配置或质量提升。

### 35. 离散扩散语言模型（diffusion）

随机 token 画布逐轮更新候选、熵筛选与稳定状态；收敛帧不提交，下一帧只提交有效长度。

可调输入：教学 Canvas 槽数、实际有效输出长度、最大去噪步数、熵累计接受界、稳定检查阈值、平均熵置信阈值。

场景：“多轮去噪后提交”、“严格熵界”、“末尾画布截短”。

教学边界：对照 DiffusionGemma 的随机 token 画布、熵筛选、稳定判定与下一步提交；logits 是教学数据。

### 36. Batch Invariance 与确定性（invariance）

以 Math.fround 比较 FP32 逐加归约，观察部分和、临界 logits 和 argmax；统一顺序后结果一致。

可调输入：大数幅度 10 的指数、候选 B 的固定 logit、两种布局使用同一归约顺序。

场景：“临界采样差异”、“共同归约顺序”、“较小数值幅度”。

教学边界：Math.fround 模拟三项 FP32 归约；固定随机种子不会消除归约顺序差异。

### 37. 插件与外部量化后端（plugins）

对照 General 与 Endpoint 的默认白名单规则；各进程注册独立，加载失败不会进入 registry。

可调输入：VLLM_PLUGINS 教学白名单、观察 endpoint 插件组、beta 加载异常、教学进程数。

场景：“一般插件逐进程注册”、“只加载 alpha”、“endpoint 默认不准入”、“beta 加载失败”。

教学边界：alpha / beta 是教学 entry point；一般插件与 endpoint 插件的默认准入不同。

### 38. NIXL / Mooncake 等 Connector（connectors）

逐层等待 KV 加载完成再消费；发送/接收完成集合分别确认后才能释放生产侧资源。

可调输入：观察 Connector 契约标签、KV 块数、每层传输确认时隙、第二层加载失败、Factory 已注册实现。

场景：“逐层完成与等待”、“第二层传输失败”、“Factory 未注册”。

教学边界：仅模拟共同 Scheduler / Worker 接口与完成句柄，不模拟这两个传输库的网络内部。

### 39. Rust 前端与跨语言协议（rust）

观察 Rust Add/Abort 类型、请求字段与输出结束枚举；ZMQ/MessagePack 与 gRPC 边界分别说明。

可调输入：教学 prompt token 数、输出阶段取消请求、请求含预计算 Prompt Embeddings。

场景：“跨语言请求与输出”、“Abort 消息边界”、“Prompt Embeddings 不支持”。

教学边界：ZMQ 单字节请求类型与 MessagePack 字段映射；gRPC schema 是独立边界。

## 原有观察过程深化

连续批处理可暂停在准入、分配、执行、采样、释放之间；时间线按钮仍指向逻辑轮次的结算帧。切块对照共享输入与轮次坐标，未完成组始终标为停滞。大工作负载超过 256 个微帧时保留所有轮次结算，避免分享链接丢失尾部。

分页 KV 逐 token 展示逻辑块、物理块、offset 和 slot；前缀逐整块查找、绑定共享引用，再计算尾部与末尾 logits。链式键是依赖说明，不模拟密码学 hash。随机投机逐位置检验，首拒绝后不检验后缀，先恢复分布再提交。

TP 按局部列累加再观察各 rank 的归并贡献，此贡献展示不代表真实 All-reduce 网络算法。PP 保持 microbatch 身份与上一时隙交接，短批次明确没有满流水线稳态。MoE 保留 token 原 rank 与 Top-2 权重，逐项 combine 后才展示已返回状态。JSON 语法状态展示允许/排除集合，字符串值可切换。

KV 卸载增加 CPU 与外部容量、LRU 淘汰和回载。选择“三层小容量 / 回载”检查目标确认前无效、源副本保留、完成后才消费；外部层代表缓存契约，不承诺所有 connector 实现三层组合。分离部署并排显示同一 Prompt 的单实例路径，比较 KV 读依赖和跨实例传输，不比较硬件性能。
