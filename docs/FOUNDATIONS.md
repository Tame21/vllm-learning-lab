# 前置基础学习指南

入口：顶部“前置基础”，或左栏 **00 前置基础 → 前置基础 · 目录与学习顺序**。本机默认地址：<http://127.0.0.1:4173/#foundations>。“学习路线”也提供入口。

这组课程面向第一次接触模型推理的学习者，先认识数学与生成模型，再进入已有的 vLLM 机制、投机方法和 24 个算法实验。每节都有白话直觉、符号表、公式、手算例子、可改参数的逐步观察窗、常见误解、理解题和应用链接。基础课不是当前 vLLM 支持特性的清单。

## 20 节课程

|    1 | 读懂公式 `base-notation`           | 下标、求和、连乘、argmax、比例与归一化    | 改变项数，逐项累计并比较最大值与索引                |

|    3 | 点积与矩阵 `base-linear`           | 对应相乘再相加、夹角与线性映射            | 旋转二维向量，观察点积及矩阵输出                    |

|   15 | Attention `base-attention`         | Q/K/V、因果掩码、上下文权重与 Transformer | 选择 query 位置、切换掩码并计算 Value 加权和        |

## 三条学习路线

- **读懂投机接受 / 拒绝**：公式 → 概率分布 → 条件概率 → 贝叶斯 → CDF → `alg-rejection` → `alg-residual`。先分清 p、q、接受阈值与条件分布，再解释为什么拒绝后要用正残差。
- **读懂模型前向**：形状 → 点积 → 指数归一化 → Token / Embedding → Attention → `alg-attention` → `runner`。注意 Attention 在上下文位置上归一化，下一词概率在词表维度上归一化。
- **读懂扩散与 MTP**：条件概率 / 贝叶斯 → 期望方差 → 高斯 → 马尔可夫链 → 连续扩散 → 离散扩散 → 生成方式对照 → `mtp` / `diffusion`。MTP 的实现结构与并行方式需核对具体模型，不能直接等同于扩散。

已有关联的机制和算法章会显示相应基础课链接。基础课使用独立 ID 保存已读、收藏、理解题和断点，保留原课程的题目顺序与成绩。

## 建议亲自做的实验

1. 贝叶斯：保留 `P(红球|H)=0.8`、`P(红球|非H)=0.1`，先验 `P(H)=0.2`。红球证据为 `0.2×0.8+0.8×0.1=0.24`，后验 `P(H|红球)=0.16/0.24=2/3`。再改变先验，看同一似然为什么会得到不同后验。
2. 条件概率：选择“第二个条件不可能发生”的案例，再选 `B=1`。该列质量为零，条件分布未定义；不要把它误写成均匀分布或全零分布。
3. CDF：用概率 `[0.2,0.5,0.3]`，先试 `U=0.19`，再试 `0.20` 与 `0.70`。本例区间为 `[0,0.2)`、`[0.2,0.7)`、`[0.7,1)`。它用于讲分类抽样，不声称 vLLM 的指数竞赛实现采用同样步骤。
4. 高斯：将 `σ` 从 `1` 调到 `0.25`。峰值可高于 1，但 `μ±σ` 的区间概率仍约为 `0.6827`。高度是密度，面积才是概率。
5. 训练：默认 `θ=0`、学习率 `0.2`，第一次更新得到 `θ=0.4`。关闭训练模式后重新播放，权重保持为 0；上下文变化和普通推理不等于重新训练基础模型。
6. 离散扩散：切换“首轮猜错，下一轮修正”。首轮低置信度“要”仍是候选，后续变为“会”才被确认。再切换预算不足，观察未确认位置和不可提交状态。

## 扩散例子的数学与实现边界

连续例子把干净数据限制为等概率的 `−1 / +1`，每步使用 `xₜ=√(1−β)xₜ₋₁+√β εₜ`，其中 `εₜ∼N(0,1)`。这允许独立核对前向均值、方差和后验。

反向链不读取前向样本或噪声日志。它从该玩具分布的精确末端边缘分布另起一条链：先根据当前 `xₜ` 计算两个干净来源的后验概率，抽取来源，再按条件高斯采样 `xₜ₋₁`。展示的条件均值和方差是已选定来源的高斯分量。终点属于 `−1 / +1`，不保证与前向样本相同。

真实 DDPM 通常通过训练网络近似反向过程，并使末端分布接近标准高斯。课程详细解释噪声预测损失，以及为何少数几步的精确玩具混合分布不能被当作真实图像模型。参考 [DDPM 原始论文](https://arxiv.org/abs/2006.11239)。

离散例子采用 Mask 损坏与预设候选，讲清一轮多个提议、跨轮更新与提交边界。Mask 是离散扩散的一种设计，参见 [D3PM 论文](https://arxiv.org/abs/2107.03006)。本例并未加载去噪网络，也不演示真实模型质量或吞吐量。

当前固定 vLLM 源码的 DiffusionGemma 文件中的模块级函数 `_compiled_sample_step`使用随机 token 画布、熵相关规则、重加噪与专门提交条件，不能把 Mask 教学例当成它的逐行重演。应用位置是 `vllm/model_executor/models/diffusion_gemma.py::_compiled_sample_step`，配置边界见 `vllm/config/diffusion.py::DiffusionConfig`。基础课的“对应源码”明确标为**概念应用 / 对照位置**。

## 维护与验证
